# VoiceRiders — beta feedback form (Google Forms)

Create a form with the title:

**VoiceRiders Beta — Feedback & Ratings**

Description:

> Thanks for testing VoiceRiders. This is an **early beta**, so bugs are expected — honest answers help more than polite ones. It takes about 3 minutes. If something broke, tell me what you said and what happened; screenshots of Ride Mode → Last command / Volume are gold.

Settings: collect email addresses **off** (keep it anonymous), limit to 1 response **off** (so people can resubmit after a fix), show progress bar **on**.

---

## Confirmation message

> Thank you! If you have a minute, send me a screenshot of **Ride Mode → Last command** and **Volume** for anything that misbehaved. Every report makes the next build better. 🏍️

---

## Viewing the responses

- **Responses → Summary** gives per-question charts (the rating grid becomes a clean table).
- **Responses → Link to Sheets** exports every answer to a spreadsheet — best for the report: calculate averages per rating, count the "improve first" options, and quote the paragraph answers.
- For the report, keep: number of responses, average overall rating, top three improvement requests, and 2–3 anonymised quotes.

## How to phrase the beta warning in invites

> **Heads-up: this is an early beta.** Bugs and rough edges are expected — the form is there to catch them, not to judge. If something fails, tell me what you said and what happened; that is genuinely more useful than a perfect score.
